# Contributing to Trade Calendar

Thank you for your interest in improving **Trade Calendar**! Follow these guidelines when reporting issues or submitting changes.

## Reporting Bugs
- Open an **Issue** with a clear title and description of the problem.
- Include steps to reproduce the issue, your browser name, and screenshots if it is a UI layout bug.

## Submitting a Pull Request
1. **Fork** this repository to your GitHub account.
2. Create a new branch for your feature or fix (`git checkout -b feature/your-feature-name`).
3. Make your changes and test both **Day Mode** and **Night Mode** across desktop and mobile views.
4. **Security Check:** Never commit personal `SUPABASE_URL` or `SUPABASE_ANON_KEY` credentials in your pull request.
5. Commit your changes with a clear message and open a **Pull Request** against the `main` branch.
