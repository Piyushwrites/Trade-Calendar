# Security Policy

## Supported Versions

Security updates and patches are actively maintained for the latest live deployment of **Trade Calendar**.

| Version | Supported |
| :--- | :--- |
| Latest (`main` / Live Vercel Deployment) | Yes |
| Older Commits | No |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub Issues.

If you discover a security issue—such as an authentication flaw, data exposure, or cross-site scripting (XSS) vulnerability—please report it privately by emailing **piyushsahoo088@gmail.com** with:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or screenshots to reproduce the issue.

You will receive an acknowledgment within **48 hours**, and a fix will be deployed as quickly as possible before any public disclosure.
